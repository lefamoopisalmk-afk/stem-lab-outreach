# STEM Lab Schools Outreach Day

A web page with a 5-minute seamless 3D loop of the STEM Lab robot head, drawn with plain WebGL and no libraries.

- `index.html` and `main.js`: the page; `main.js` holds the player and the model
- `loop.glb`: the exported model and animation
- `loop.blend`: the Blender source scene (Blender 5.2)
- `preview.mp4`: the whole 5-minute loop rendered in Blender (1280x720, 24 fps)
- `source/`: scripts that rebuild everything and check the export
